# 井字棋 AI 人机对战
人工智能导论课程项目，基于极小极大算法实现AI博弈，网页版可直接运行。

## ✨ 功能介绍
- 玩家：X，先手
- AI：O，使用极小极大搜索算法，最优策略落子
- 自动判断胜负、平局
- 一键重置游戏

## 🧰 技术栈
HTML + CSS + JavaScript
无需额外环境，浏览器直接打开游玩。

## 📌 部署
本项目使用 GitHub Pages 在线部署。
访问地址：https://chenhes.github.io/tict/

## 📖 算法说明
极小极大（Minimax）算法：
1. AI 是极大方，寻找最高分；玩家是极小方，寻找最低分
2. 递归遍历所有落子情况，评估局面分数
3. 选出最优一步，AI不会失误

## 📝 课程用途
人工智能导论博弈搜索课程演示项目。
