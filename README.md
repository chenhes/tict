# 本地文件整理助手｜人工智能导论 Agent课程项目
> 项目选题：基于浏览器纯前端的本地文件整理工具，人机协作开发，WorkBuddy Agent提供方案、代码模板，人工掌握全部执行决策权

## ✨ 项目功能
1. 本地文件夹按后缀自动归类（PDF、图片、压缩包、文档、日志）
2. 黑名单过滤：dataset/data数据集zip跳过移动，防止实验代码报错
3. **预览机制：执行前完整预览全部变更，不预览绝不改动磁盘**
4. 完整操作日志，导出CSV记录，支持回滚
5. 单HTML文件，**无需安装任何软件，Edge/Chrome浏览器直接打开**，不上传任何本地文件

## 📦 项目架构
四层架构：使用者 → WorkBuddy Agent → 浏览器网页 → 本地磁盘
> Agent只输出方案，无权读写本机文件，全部高危操作人工确认

## 🚀 使用方法
1. 下载 index.html，Edge浏览器打开
2. 第一步：选择你想要整理的文件夹（不要选系统目录）
3. 第二步：生成预览，查看待移动文件清单
4. 第三步：确认执行整理，导出操作记录CSV

## ⚠️ 安全底线
- 不上传任何本地文件到网络
- 不修改文件内容、不改文件名
- 所有改动留有记录，支持回滚恢复
- 高危系统目录禁止操作

## 📌 开发复盘
Agent生成通用分类规则，但是无法感知本机实验项目依赖，出现数据集zip误移动问题；由此得出设计原则：**所有修改本地资源的AI工具，必须强制预览，人掌握最终决策权**。
